## Method (what changed)
- The widget is not always top-right (it is bottom centre in videos 1886 and 1887), so each sample is read twice: the whole frame at 1.5x and a 3x lanczos crop of the top-right quadrant (`ocr2_run.py`, ffmpeg `fps`+`crop`+`scale`, Windows OCR). Job sets: (1) 98 of the 160 challenge videos, whole video, 2 s step (the 62 housing "Custom-Built Decor"/"Wildman" playthroughs skipped); (2) 140 s windows at 2 s around subtitle cues that name a flagged challenge (76 windows, outside set 1) plus two metadata hits; (3) 100 s windows at 4 s around cues that say "challenge" in videos outside set 1, 2014-2015 first (about 750 of 1163 windows done, then stopped; 2013 and 2016-2018 windows not read). About 40 000 frames read in total.
- `ocr2_analyze.py` clusters mm:ss readings by `frame time + remaining` and drops static readings (system clock, chat timestamps), which gave false clusters in the whole-frame text; `ocr2_names.py` lists frames showing a flagged name (all 538 distinct `Challenge.tbl` names are matched); `ocr2_sheet.py` makes labelled crop sheets. On the 62 videos shared with pass 1 the cluster frames rose from 1900 to 2723 (+43 percent); no new cluster appeared inside the 160-video set, the new limits came from the dense look at start frames, from set 2 and from set 3.
- Pattern in every clip with a visible start: the 2014 widget appears at **limit minus 1 to 2 s** (Thayd Sprint 1:58, Ravenok Racer 0:58, Bingberries 5:58-5:59, Entrance Exam 9:58, Doing Things The Hard Way 19:58-19:59, Windspire Ascent 0:44, Top of the World 0:78-79, Up the Falls 1:59 at the "Challenge begins!" banner). Where only one video exists the limit is the next round number, labelled probable.
- Final-era HUD: the header "Challenge Active!" stays on screen for the whole run (video 5539 shows it on every frame), so it does not mark the start there; only the 2014 "Challenge begins!" banner does. Frame times from the OCR run and from single-frame extraction differ by 1 to 2.5 s in some clips; gaps below were judged on extracted frames.
