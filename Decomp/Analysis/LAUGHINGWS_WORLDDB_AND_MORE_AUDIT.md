This note tracks how the LaughingWS world database repository is being used.
Do not point setup's `-WorldDatabasePath` directly at this checkout: the
repository contains useful hand-authored content, but it also contains broad
world replacement dumps, DDL, delete scripts, WIP event data, test zones, and
branch-local assumptions. Current runtime-owned seeds, the official world DB,
DataMapping review output, setup import rules, and focused tests stay
authoritative.

Remaining smoke/proof-only blockers from the implementation plan are tracked
task-by-task in
`Decomp/Analysis/LAUGHINGWS_REMAINING_BLOCKERS_CLOSURE_MATRIX.md`: unproven
WorldDB slices remain WIP/GUESSED, mapped-only, or explicitly rejected until
the named evidence is captured.
